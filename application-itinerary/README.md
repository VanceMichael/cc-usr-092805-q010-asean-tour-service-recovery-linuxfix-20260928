# 面向每位游客的线路版本与服务恢复应用（application-itinerary）

构建在协同事务平台（`../src/civicflow` 的机构、版本化实体、资源预约、审批、
不可变资金分录、收件箱、发件箱通知与可恢复任务队列）能力之上的旅游履约应用。
纯 Node 22 标准库（`node:sqlite`），TypeScript 严格模式，无任何运行时第三方依赖。

## 解决的问题

小众线路遇到航班改期、供应商退出、容量缩减或目的地风险时：

- **版本按人冻结**：每个出发批次保存逐日行程、交通/住宿/活动供应、容量、价格构成
  （基础价/附加/税）、签证或入境条件、导游资质、特殊需求与允许的替代范围；
  游客确认后冻结其**实际购买版本**，批次后续修订不影响该订单。
- **只处理尚未履行的环节**：服务履约状态为 未履行/使用中/已使用/已取消；
  供应商退出、容量缩减、风险或航班变化只影响未履行环节；已使用服务保留原责任，
  下一责任方直接指向原供应方，不产生退款或替代。
- **替代三维比较**：提出替代时同时比较时间（开始时刻/时长变化）、价值
  （价格构成合计差额）和无障碍（特殊需求逐条核对）；无障碍不达标游客不能接受；
  替代必须落在批次与环节允许的替代范围内（不可替代/仅同类/资质保留）。
- **权益逐环节守恒**：补差、退款、代金权益每一行都对应被影响环节；
  退款+代金不得超过该环节游客实际支付；无替代按环节全额退款。
- **高额补偿双人确认**：客服发起的 ≥ 500.00 补偿进入审批，必须由另一名审核人员
  决定（提交者不能自审），未通过前结算不能过账。
- **供应商隔离**：供应商只能看到本机构的目录服务与相关恢复单。
- **回执幂等与矛盾挂起**：相同状态回执重复推送只返回 `duplicate`，绝不触发
  第二次退款；同序号但内容矛盾的消息进入 `inbox_conflicts` 挂起，等待人工核对，
  业务不推进。
- **重启自动续接**：临近出发提醒、待确认替代到期、退款对账均为可恢复任务；
  应用重启时回收过期租约并续跑，发件箱通知同步续投。

## 页面

| 页面 | 使用者 | 内容 |
| --- | --- | --- |
| `/traveler?booking=…` | 游客 | 冻结版本逐日行程、变更原因、替代的时间/价值/无障碍比较、权益如何计算、下一责任方 |
| `/operator` | 运营/客服 | 全部未关闭恢复单、下一责任方、转退款/生成结算/过账/对账、原责任保留归档 |
| `/reviewer` | 独立审核人 | 高额补偿审批（发起人本人不可审） |
| `/supplier?org=…` | 供应商 | 只列本方任务，可重放状态回执（重复/矛盾） |
| `/conflicts` | 运营 | 内容矛盾消息的核对台 |

## 构建与运行

```bash
npm install        # 仅安装本地 tsc（devDependency），运行时零依赖
npm run build
npm test           # tsc 严格编译 + node:test 11 项不变量测试
ITINERARY_DB=/tmp/itinerary.sqlite3 PORT=8080 npm start
```

首次启动自动播种越南河内·宁平小众四日线演示数据：航班 VN553 改期、东湖非遗
版画工坊退出；同团四人分别覆盖 待确认替代、已入住酒店（原责任保留+风险归档）、
轮椅无障碍需求保护、已全额退款并对账通过 四种路径，以及一笔等待二审的高额补偿。
设置 `FIXED_NOW`（带时区 ISO 8601）可固定时钟以便演示与复现。

## 数据与平台能力对应

| 应用概念 | 沿用的平台能力 |
| --- | --- |
| 机构 / 服务目录 / 批次 / 订单 / 恢复单 / 结算单 / 补偿审批 | `entities` + `entity_versions` 版本化实体、乐观并发、请求幂等键 |
| 谁在何时改了什么 | `audit_entries` SHA-256 哈希链 |
| 环节与替代容量 | `resource_reservations` 窗口容量预约 |
| 补差/退款/代金/补偿 | `journal_entries` 不可变分录（参考号唯一、可冲正） |
| 高额补偿 | 补偿审批实体 + 职责分离（`assertDistinct`） |
| 供应商/航司回执 | `inbox_messages` 序号去重、`inbox_conflicts` 矛盾挂起 |
| 游客与运营通知 | `outbox_messages` 租约投递，重启续投 |
| 临近出发/替代到期/退款对账 | `scheduled_jobs` 租约领取、失败重试、过期回收 |

所有金额按最小币种单位（分）以整数记账，时间均为带时区 ISO 8601。
